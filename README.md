# CODIGO ESCONDIDO 19

## Versión final: 1.9
## Abrir en la web

La aplicación web se abre desde:

https://programadorcodigoescondido19.github.io/ce19/

## Descargar la aplicación

- [Abrir la última publicación de GitHub](https://github.com/ProgramadorCodigoEscondido19/ce19/releases/latest)

En la publicación, descarga el APK de Android, el ZIP de Windows o el ZIP de macOS.

En Windows, descomprime el archivo ZIP y ejecuta `CODIGO ESCONDIDO 19.exe`.
En macOS, descomprime el ZIP y abre `CODIGO ESCONDIDO 19.app`. Como el paquete
no está firmado por Apple, puede ser necesario autorizarlo desde Privacidad y seguridad.
