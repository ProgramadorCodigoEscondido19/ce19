# CODIGO ESCONDIDO 19

## Versión: 1.9

Los paquetes nuevos se reúnen en `Para_compartir/`. En Ajustes se puede silenciar
el añeñe del resultado 8. Tiempo y Apophis están disponibles desde el nivel 1.
Inicio actualiza su lista cuando se elimina un diccionario en Ajustes.
La página **Aro Arcoiris** representa dinámicamente cada libro bíblico con una
corona de capítulos y otra de cantidades de versículos, y permite exportarla a PNG.

La versión 1.9 descarta los accesos recordados de versiones anteriores. Ingresa
la clave de cada nivel y marca «Recordar acceso» solo si deseas conservarlo.
Los instaladores excluyen la configuración y los accesos del equipo de desarrollo.
## Abrir en la web

La aplicación web se abre desde:

https://programadorcodigoescondido19.github.io/ce19/

## Descargar la aplicación

- [Abrir la última publicación de GitHub](https://github.com/ProgramadorCodigoEscondido19/ce19/releases/latest)

En la publicación, descarga el APK de Android o el ZIP de Windows.

En Windows, descomprime el archivo ZIP y ejecuta `CODIGO ESCONDIDO 19.exe`.
