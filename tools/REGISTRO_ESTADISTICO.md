# Registro estadistico

1. Cree una hoja de calculo de Google para los registros.
2. Abra **Extensiones > Apps Script** y pegue el contenido de `registro_estadistico.gs`.
3. Despliegue el script como **Aplicacion web**, con acceso para cualquier usuario.
4. Copie la direccion web del despliegue en **Ajustes > Registro estadistico** dentro de la aplicacion.

Los registros pendientes se enviaran cuando un usuario nuevo complete el formulario con el enlace configurado. La aplicacion tambien consultara esta misma direccion para mostrar el total y la cantidad por pais en el mapa.
